    Game Guides (Blog)

    Hub Guides đã redesign. Viết/rewrite bài SEO bằng script template — giữ static HTML, không cần WordPress.

    Luồng khuyến nghị

    • Hub: /blog/ — featured, Monkey Mart, hot, filter search.
    • Template: CTA Play, FAQ, related, sticky play bar, dark chrome khớp site.
    • Priority guides: 20 bài top đã rewrite (Slope, Monkey Mart, Retro Bowl, 2048…).

    Tạo / rewrite bài

    Chạy trong terminal (thư mục repo):

    # Liệt kê slug ưu tiên
python3 scripts/new-blog-post.py --list

# Rewrite toàn bộ 20 guide ưu tiên
python3 scripts/new-blog-post.py --all-priority

# Một game
python3 scripts/new-blog-post.py --slug slope

# Bài mới nhanh
python3 scripts/new-blog-post.py --write \\
  --name "My Game" --game /game/my-game.html \\
  --file play-my-game-online.html \\
  --image /assets/img/img-up/my-game.png

    Sau khi generate: mở guide → hard refresh → kiểm tra CTA Play Now.
